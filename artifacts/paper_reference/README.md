# Inputs for the paper's aggregate figures

These aggregate values generate the representation, mask-budget and Prob-U figures. Use them with `ssrb plot-paper --profile representation|budget|probunet` as shown in [PAPER_ANALYSIS.md](../../docs/PAPER_ANALYSIS.md).

To plot your own results, supply the same CSV/JSON structure with values from the corresponding completed analysis. Image-based figures require separately obtained dataset images and predictions.
